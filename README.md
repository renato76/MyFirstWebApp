# My Interest in Mountain Landscapes

A simple HTML web page created for the Web Technologies module to demonstrate HTML structure and inline styling.

## About the Page

The page explores my interest in mountain landscapes, particularly winter scenery and snow-covered mountains.

It includes:

- A main heading and introductory paragraph
- Navigation links to different sections of the page
- Information about winter mountain landscapes
- Images of mountain scenery
- Useful external links
- Inline CSS styling using HTML `style` attributes
- A responsive flexbox layout for the images

## Technologies Used

- HTML5
- Inline CSS
- Git
- GitHub
- GitHub Desktop
